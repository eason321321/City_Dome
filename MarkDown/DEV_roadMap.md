  - **左鍵拖曳**：基於射線檢測的「抓地拖曳（Ground Plane Drag）」，提供極致真實貼地手感。

  - 支援每幀阻尼插值（Lerp Damping），操作手感絲滑。

## 階段 1：網格系統與路網有向圖編輯 (Grid & Road Network) `[狀態: 基礎道路穩定版本已完成]`
> **目標**：讓玩家能在 3D 地面上自由鋪設道路、拆除道路，後台自動計算路網節點與交叉路口。

### 核心任務清單：
- [x] **網格地圖與射線檢測**：建立地面網格（Grid），支援 2m 次要網格吸附（Snap to Grid）與射線碰撞檢測。
- [x] **路網有向圖管理器 (`RoadNetwork.ts`)**：
  - 雙向二線道有向車道圖（Directed Lane Graph）動態維護。
  - 兩路相交時自動動態融合並切換拓撲（Straight、Corner、ThreeWay、FourWay、DeadEnd）。
  - 自動生成立體 3D 高架人行道（高 0.035m、寬 0.35m）與入口純白枕木紋斑馬線。
  - 相交路口動態生成 3D 低多邊形紅綠燈號誌燈柱（8s 綠燈 / 2s 黃燈 / 1s 全紅狀態機循環）。
- [x] **道路建造選單 (`BuildMenu.ts` / `RoadManager.ts`)**：
  - 畫面左下方現代暗色毛玻璃建造選單，整合懸浮專業道路資訊面板（是否雙向、限速、人行道、停車、迴轉）。
  - 拖曳預覽（水藍色合法吸附 / 紅色超額不可建造）、國庫金錢扣減（每格 $10）與右鍵/ESC 取消。
- [ ] **推土機工具 (Bulldozer Tool)**：點選或框選拆除道路，自動修復周邊鄰接節點。

## 階段 2：車輛尋路與交通流模擬 (Traffic & A* Pathfinding) `[狀態: 基礎車輛行駛與號誌停等已完成]`
> **目標**：車輛能在道路網絡中尋找最短路徑，有起點與終點，具備平滑加速、減速、轉向與紅綠燈停等機制。

### 核心任務清單：
- [x] **3D 低多邊形程序化車輛模型 (`VehicleModelFactory.ts`)**：
  - 組裝烤漆車身、座艙、前後傾斜擋風玻璃、車窗、發光大燈與煞車燈、四輪橡膠輪胎與輪轂。
  - 等比縮放 0.9 倍，精準適配 0.65m 單向車道淨寬。
- [x] **路網 A\* 尋路引擎 (`Pathfinding.ts`)**：
  - 車道級有向圖搜尋最短路徑，結合 Bézier 曲線取樣連續平滑航點序列。
  - 自動標記路口停止線（`isStopLine`），精確關聯號誌控制器。
- [x] **車輛運動與號誌停等系統 (`VehicleManager.ts`)**：
  - 車輛依循航點前進，居中於對向黃虛線與外側白邊線正中央（`LANE_OFFSET = 0.325m`）。
  - 最短弧度角平滑轉向插值。
  - 前瞻停止線安全制動（$6\text{m}$ 內依 $v = \sqrt{2ad}$ 平滑減速），紅黃燈於停止線前 $0.25\text{m}$ 煞停，綠燈起步放行。
- [x] **左上角開發者道路測試選單 (`DevMenu.ts`)**：
  - 抽屜式毛玻璃面板，支援互動式 3D 拾取起訖點、立體光柱旗標、發光導航軌跡繪製與發車實測。
- [ ] **多車避讓與車距防撞跟車模型**：前後車跟車車距保持與壅塞動態排隊。

## 階段 3：土地分區與建築動態生長 (Zoning & Building Lifecycle)
> **目標**：玩家規劃住宅、商業、工業區（RCI），建築隨時間與周邊條件自動破土動工並升級。

### 核心任務清單：
- [ ] **分區規劃筆刷 (Zoning Tool)**：
  - 沿道路兩旁網格劃定 R/C/I 分區色彩。
  - 檢測建築網格是否具備「臨路通路（Road Access）」。
- [ ] **建築生長狀態機 (`BuildingSystem.ts`)**：
  - 空地劃定 $\to$ 施工中（鷹架/地基） $\to$ Level 1 建築物落成。
  - 需求滿足（地價高、通水電、無污染）時晉級至 Level 2~5。
  - 條件惡化（無路、火災、嚴重污染）時降級或廢棄（Abandoned）。
- [ ] **建築容量與產能**：住宅提供人口上限、工商業提供就業職缺。

## 階段 4：市民個體模擬與 24 小時作息 (Citizen Agent Simulation)
> **目標**：市民擁有真實住家、工作地點，每天依照 24 小時時鐘規律通勤、生活與產生情緒。

### 核心任務清單：
- [ ] **虛擬時鐘推進系統 (`TimeSystem.ts`)**：
  - 邏輯 Tick 換算為 24 小時制（例如 10 實際秒 = 1 虛擬小時）。
  - 支援暫停、1x、2x、4x 加速。
- [ ] **市民日常作息狀態機 (`CitizenSystem.ts`)**：
  - 早晨：在家起床 $\to$ 開車/搭車前往工作地（觸發上班車流高峰）。
  - 白天：在商業/工廠上班。
  - 傍晚：下班 $\to$ 前往商業區娛樂消費或直接回家（觸發下班車流高峰）。
- [ ] **市民需求與滿意度計算**：
  - 計算通勤時間長短（塞車降低滿意度）。
  - 綜合生成總體幸福度指數（Happiness Index）。

### 核心任務清單：
- [ ] **程式化道路渲染器 (`RoadRenderer.ts`)**：
