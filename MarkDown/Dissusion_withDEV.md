# 與開發者討論紀錄 (Discussion with DEV)

## 專案概述與願景
- **專案名稱**：City Dome - 網頁 3D 城市建造模擬器
- **核心目標**：以 Three.js 為主體，打造具備真實市民模擬、車流尋路與多維度資料視覺化的現代 Web 模擬建造遊戲。

---

## 核心功能需求確認
1. **路網與車輛尋路系統 (Vehicle Pathfinding & Road Network)**
   - 道路以「有向加權圖（Directed Weighted Graph）」為數據底層，包含節點（路口）與邊（車道）。
   - 車輛具備尋路功能（A* 演算法），並根據即時路段擁擠度動態計算通行成本，實現自適應繞道與避堵。
2. **市民個體即時運算 (Citizen Behavior Runtime Simulation)**
   - 市民擁有日夜生活作息狀態機（睡覺 $\to$ 通勤 $\to$ 工作 $\to$ 休閒 $\to$ 回家）。
   - 具備各項需求指標（滿意度、健康、教育、通勤舒適度），直接影響城市活力。
3. **建築物狀態隨時間推移演進 (Dynamic Building State Progression)**
   - 土地分區（住宅、商業、工業、市政公共服務）。
   - 隨時間 Tick 更新建築狀態（規劃中 $\to$ 施工中 $\to$ 正常運作 $\to$ 衰微/廢棄/火災）。
   - 建築等級升級受公共服務（水、電、警察、醫療、地價）驅動。
4. **多維度檢視地圖（Data Overlays & View Modes）**
   - 支援無縫切換多種數據圖層：一般全彩模式、交通擁擠度熱度圖、市民滿意度分佈圖、地價等級圖、環境污染圖。
   - 透過 Shader 動態著色，避免頻繁替換網格材質導致效能崩潰。

## 最終技術選型與開發工具清單 (2026-11-10 開發者確認定案)

本專案採用的完整技術鏈與選型如下：

### 1. 核心開發與構建環境
- **構建工具**：`Vite`（極速 HMR 熱更新，對 Vibe Coding 最佳）
- **開發語言**：`TypeScript`（嚴格型別模式，提供最高質量的代碼提示與編譯期防錯）
- **3D 引擎**：`Three.js`（輕量、成熟、社群範例最龐大）

### 2. 3D 物件呈現方案【開發者拍板定案】
- **方案**：**物件程式化低多邊形 (Procedural Low-Poly Primitives)**
- **實作策略**：
  - 不引入龐大外部 3D 模型檔，所有房屋、車輛、道路、市民均使用代碼動態組裝幾何原型（Box、Cylinder、Extrude 等）。
  - 大規模複用幾何體，搭配 `THREE.InstancedMesh` 實現數千物件單一 Draw Call 繪製。
  - 保留幾何工廠（Geometry Factory）抽象層，未來可隨時無痛升級為 GLTF 外部模型。

### 3. 音效系統架構【開發者拍板定案】
- **方案**：**自封裝 `SoundManager` + 瀏覽器原生 `Web Audio API`（3D 空間音）+ `ZzFX`（程式化音效合成）**
- **實作策略**：
  - **UI 與操作反饋音**：透過不到 1KB 的 `ZzFX` 演算法即時以數值參數合成，純代碼發聲，無須加載 MP3 音檔。
  - **環境音與 3D 空間音**：透過 Three.js `AudioListener` 綁定主攝影機，並於各主要交通路口或設施掛載 `PositionalAudio`，實現鏡頭拉近變大聲、拉遠模糊化的沈浸式音場。

### 4. 系統整體架構原則
- **雙層解耦架構**：
  - **模擬運算層**：純 TypeScript 數據結構，固定 Tick 邏輯運算，不碰 DOM，支援未來無縫移至 Web Worker。
  - **視覺渲染層**：Three.js 專職畫面繪製與 Transform 矩陣更新。
  - **UI 覆蓋層**：HTML + CSS 懸浮儀表板與工具面板。

## 移動系統技術探討：網格離散與子網格/連續座標 (2026-11-10 討論)
- **問題探討**：遊戲由網格組成，車輛與行人是否能移動到單個網格的各個位置而非僅限中心？
- **技術結論**：
  1. **完全可行且為業界標準**：網格（Grid）負責邏輯管理（占地、分區、A* 搜尋圖節點）；實體（Entity）則運行於 Three.js 連續浮點數空間（`Vector3D`）。
  2. **多車道偏移 (Lane Offset)**：在單一路網格內，車輛根據車道索引（`currentLaneIndex`）維持向左/向右的空間偏移（如 $\pm 2.5\text{m}$），避免雙向對撞。
  3. **平滑樣條曲線 (Spline / Bézier Curve)**：路口轉向或路段移動採用參數化曲線 $t \in [0, 1]$ 進行插值，車輛能平滑穿過格子內任意軌跡。
  4. **人行道邊界與散布**：行人定位於道路外側邊緣（如 $\pm 4.5\text{m}$），並可附帶微幅隨機微擾（Jitter），營造真實的人流錯身效果。
  5. **與目前架構相容性**：現有 `src/types/vehicle.ts` 與 `src/types/road.ts` 已設計好 `segmentProgress`、`currentLaneIndex` 與 `Vector3D`，後續開發可無縫銜接。

## 3D 車輛模型建構、車輛行駛與號誌停等系統、左上角開發者道路測試選單 (2026-11-10 第 13 輪)
